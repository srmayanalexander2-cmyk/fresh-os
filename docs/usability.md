# FreshOS 1.4: desktop and storage repairs

## Start here

* **Back from the shell:** click **Desktop / Esc**, press Escape at the command-desktop prompt, type `exit` (or `gui`), or use F3. Inside a dialog Escape dismisses the dialog first. `exit` from Terminal also returns to the graphical desktop. The pointer is visible in both shells. The kernel still uses PS/2 input with negotiated VMware absolute coordinates where available, not a host mouse-speed preference.
* **VMware disks:** extract the *entire* VMware ZIP to a writable directory and open its `.vmx`. The ISO alone, mounted as a CD, is not a writable hard disk. Files → **Drives** or `disks` (`lsblk`) shows detected IDE slots, optical drives, supported AHCI/virtio disks, and the Home/installer status. The prepared VMDK is a detected install target, **not** a mounted filesystem until installed. Use Setup only with the supplied or explicitly marked target. Never attach your only copy of important data to an experimental OS. Disconnect other candidates before installation. The kernel scans the two legacy IDE channels, including slave positions, for disks and for the FreshOS optical source. A normal foreign disk can appear in inventory without being eligible for writes. An unsupported SCSI, NVMe or USB disk will not magically work by changing its filename. `doctor` shows the bindings in use. The new VMX logs COM1 to `FreshOS-serial.log`.
* **Windows and rail:** click `+` to maximize and `<>` to restore, or use Win+Up / Win+Down. Writer reflows its document and Terminal expands its scrollback view. Apps designed for a fixed canvas keep their controls centered in the larger frame. Win+D/M shows the desktop, Win+E opens Files, Win+I Settings, Win+B the tray, Win+Shift+S starts a snip. Launcher cells measure text in pixels; labels that cannot fit are ellipsized. The launcher and tray arrows reverse when open. Animations integrate elapsed ticks; Lite defaults to reduced motion. This is not a measured performance comparison with macOS.
* **Settings:** More settings (Tab) offers rail auto-hide, Fill screen vs Keep aspect, and soft/silent interface sounds. Move to the left edge to reveal the hidden rail. Save profile to keep changes on Home; 1.x profiles remain readable. Fill stretches the logical 1280×720 canvas across the **guest** framebuffer; it does not control VMware's host window size or negotiate a new display mode on host resize. The working volume/brightness controls use the original smiley artwork, a draggable green bar and a yellow bubble. Brightness is silent software dimming. Volume preview uses an enveloped PCM chime on supported audio, not a PC-speaker square wave.
* **Right click:** copy or paste text in Writer, Stickies, To Do or Terminal; copy the last notification or a program failure; open Terminal, Settings or Task Manager; show the desktop. Copy is whole-document/current-input, not arbitrary mouse selection. Credential and consent dialogs do not expose this menu. Setup has a Copy disk report button. On a fatal CPU exception after the IDT is initialized, FreshOS stops rather than continuing disk writes. The screen and serial log give the vector, instruction pointer, CPU error code and (for a page fault) fault address. A hung machine, power loss or a fault before handlers exist cannot guarantee a crash report. A halted kernel cannot use a live clipboard: use the host screenshot or serial log.

## Install something, then uninstall it

1. Start an installed system with writable Fresh Home. In **Files → Library**, select `hello32.imp` and click **Install app** (or press `i`). For a supported `.exe`, convert it to IMP first.
2. Open **Software** in Start. Select the installed program and click **Run**. The catalog contains its executable bytes, not a shortcut pointing to the source file. It survives guest reboot.
3. In Software click **Uninstall**, then **Confirm?**. The corresponding shell commands are `pkg install demo hello32.imp`, `pkg list`, `pkg run demo`, and `pkg remove demo`. Removal affects the installed copy, not the source or the kernel's built-in utilities. Old versions occupy space in the append-only Home log. This is not MSI/MSIX, apt, a network store, or a universal installer. Up to 32 entries share a 256 KiB catalog. Rejects malformed IMP input before installation; runtime ABI limits still apply.

**Photos:** open `snip.bmp` from Recent, or import a supported BMP into Home and type `open NAME.bmp`. Photos decodes uncompressed 16-bit RGB555, 24-bit BGR or 32-bit BGRX images and scales a preview. Top-down and bottom-up rows are supported. No camera, JPEG/HEIC, online library or editing pipeline.

**Shell:** `head FILE`/`tail FILE` (up to ten lines), `stat FILE` (byte length), `wc FILE` (bytes, ASCII words and newlines), `history`, `uptime`, `disks`, `doctor`, and `pkg` operate on real session or Home data. Several familiar names invoke native operations: `cls`, `dir`, `type`, `doskey /history`, `tasklist`/`ps`, `explorer`, `notepad`, `taskmgr`, `control`, `msinfo32`, `appwiz.cpl`, `ipconfig`/`ifconfig`, `lspci`. They do **not** implement the original programs' flags, scripting languages or ABIs. `help`, `start`, `utilities` and `help drivers` describe the native interface.

## What this update does not deliver

The later wishlist spans several products. The [original feature-by-feature matrix](coverage.md) still applies. These groups are outstanding, unless a specific FreshOS counterpart is documented above. Requested historical Windows status/dates are not used as evidence of an implemented feature.

| Group | Remaining work and boundaries |
|---|---|
| Aero Browser, IE11, EdgeHTML/WebView | [1.5 ships Aero](aero.md) with IPv4 DNS/TCP, limited HTML and a bounded ES5-like script engine. No Chrome-equivalent browser ships. A Chrome-feature-equivalent browser needs DNS, TCP, TLS and certificate validation, a process/permissions boundary, a maintained HTML/CSS/JS engine, storage, input/compositing, downloads, and conformance tests. A search-box screenshot, offline help page, or host browser window is not a native browser. |
| Command suites and packages | No complete Windows CMD, PowerShell, WMI/WMIC, POSIX shell or Linux userland, registry, services, general pipes, hierarchical directories, arbitrary installer or full package/dependency ecosystem. Commands must be scoped to a named OS version, installed distribution and package set to be exhaustively testable. |
| Productivity and communications | No Skype, Teams, 365, Outlook/Outlook Express, Mail, OneNote, People bar, Wallet, Phone Link, Lens, Reader, Dev Home, Family, remote Quick Assist, Feedback Hub or social-network clients. Writer is plain text, not WordPad rich text; To Do, Calendar, Stickies and Tips are local counterparts only. |
| Media, games, cloud | No general Media Player/Groove, Movies & TV, Clipchamp, Sound Recorder, voice typing, Camera, Game Bar, Xbox, Solitaire collection, Maps, Weather, News, OneDrive/backup, Microsoft Store or business/education private store. WAV playback, BMP Photos and Minefield do not substitute for these services. |
| 3D and devices | No Mixed Reality, HoloLens, SteamVR, 3D Viewer/Builder, Babylon.js Sandbox, Paint 3D, casting, hotspot, universal audio/network/GPU/storage/touch/ink/printer/game-controller drivers or automatic online driver catalog. Native VMware pointer support is not the complete VMware Tools suite. |
| Shell customization | No live tiles, Start groups/folders, universal search index, pinned/recommended-file migration, multi-edge/resizable taskbar, people/news deskbands, jump lists, Peek/Shake/Snap tiling, touch gestures, full ribbon/context extensions, folder thumbnails, saved searches, lock-screen widgets, cross-device Timeline, wallpaper roaming, kiosk/S mode, screen saver, emoji picker, multi-monitor moves, per-app notification policy or all listed Win-key chords. Maximizing one foreground session is not multiwindow composition. |
| Security, legacy services and APIs | No Defender/Exploit Protection, EMET, Syskey, Application Guard, security enclaves/WIP, cryptographic identity, admin elevation, hotpatch, deployment/Test Base, firewall stack, Kerberos/NTLM, DirectAccess, WebDAV, Computer Browser, mailslots, password notification APIs, AllJoyn, MSDT/Steps Recorder, VBScript, UWP/ARM32, Maps/location APIs, old DRM/Type 1 fonts, Rust Win32 kernel modules, ReFS, Hyper-V switching or full enterprise network/management stack. Insecure TLS, DES, and weak authentication should not become defaults. |
| Administrative panels and extras | No full Windows Tools, Disk Management/partition editor, Performance/Resource Monitor, Task Scheduler, accounts, system policy, network sharing, region/locale suite, speech/math recognition or Windows Search. Inventory, marked-disk installation, task switching and basic settings are narrower. No Android runtime, Edge, Copilot or Recall. |

Recommended next milestone for **Aero Browser**: isolate the network/parser/renderer from kernel memory; add authenticated TLS and a standards-based rendering engine and test against real sites. Keep that work separate from maintaining a bootable small-memory edition.

### Expanded request index (duplicates consolidated)

This is a scope index, not a claim that the Windows removal dates or shortcut descriptions in the request are accurate. **Unlisted as working below means not implemented**, including items repeated in more than one historical Windows version.

* **App counterparts present:** local Calculator, File Explorer → Files, Notepad/WordPad → plain-text Writer, Paint (2D), Alarms & Clock → Clock, Calendar (month view only), Microsoft To Do, Sticky Notes, Snipping Tool/Snip & Sketch, Windows Terminal → Fresh shell (not a PTY host), Windows Tools → limited System/driver inventory, Photos → BMP viewer, Tips/Get Started/Get Help → offline Tips only, Programs and Features → Software for local IMPs.
