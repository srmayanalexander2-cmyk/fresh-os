# Hardware and application guide · FreshOS 1.2

FreshOS ships its own in-kernel drivers. Press **D** in Setup, open **System → Device inventory**, or type `drivers` / `lspci` in Terminal. The inventory reports actual PCI bus/device/function and vendor/product IDs, not an assumed list based on edition. A class name means **identified**, not necessarily driven; specific bindings are labelled. Built-in drivers probe at boot and ship on the installed disk. There is no online driver store, unsigned module installer, or universal fallback for devices without a matching driver.

| Device or transport | What works | Important boundary |
|---|---|---|
| Display | VBE (BIOS) or RGB/BGR GOP (x64 EFI), 1280×720 native desktop, aspect-preserving fallback; two VRAM pages on matching Bochs DISPI adapters. Native cursor damage updates avoid repainting the sky on every mouse packet. | No accelerated Intel/AMD/NVIDIA 3D or general display hotplug. Use 1280×720 at 100% host scaling for the sharpest output. Normal/VMware use a 24-bit sky; Lite wallpapers are 960×540. Text and controls are rendered at the same resolution on all editions. |
| Audio | Intel 8086:2415 AC’97 PCM output with 48 kHz stereo DMA; `audio test` or `open chime.wav`. Named WAV clips from Home: little-endian PCM16, mono/stereo, 8–48 kHz, up to 3 seconds. | Interface feedback stays silent if no AC’97; no HD Audio, USB audio, input or long-form media playback. On AC’97 the level scales the PCM amplitude. The PC speaker has no analog volume control. Brightness dims the framebuffer, not the monitor backlight. |
| Disk | Legacy ATA (both channels, master/slave), transitional PCI virtio-blk (1af4:1001, writable, legacy I/O and flush), SATA disk on AHCI (512-byte logical sectors, 32-bit DMA). Installer rechecks consent marker, verifies sectors, publishes MBR last. | Installer scans IDE ATAPI devices for the FreshOS ISO. No NVMe, USB mass storage, general NTFS, arbitrary disk formatting, SATA optical source or 4Kn. First eligible Home/marked target, in IDE → virtio → AHCI order. Do not attach more than one candidate target. |
| Wired or VM network | AMD PCnet (1022:2000), Ethernet DMA, IPv4 DHCP discover/request/ack, gateway ARP. Click the wireless glyph → **Request DHCP**, or `net dhcp`, then `net`. | Wi-Fi adapter | ESP-AT station firmware over **COM2** (0x2f8, 115200 8N1). `wifi scan`, `wifi join SSID`, `wifi ip`, `wifi ping HOST`, `wifi leave`. A join prompts separately for the passphrase. Not a driver for an integrated Intel/Realtek/Broadcom card. Adapter firmware controls its own persistent settings. No USB-serial driver. Do not connect PC RS-232 voltage directly to TTL pins. |
| Bluetooth adapter | HCI H4 on **COM3** (0x3e8, 115200 8N1). `bt info` resets controller and reads address; `bt scan` runs a bounded classic inquiry and reports returned addresses. | Discovery only. No Bluetooth USB, BLE GATT, pairing, HID, audio profiles or file transfer. Requires a controller already configured for H4 at this baud rate, no hardware flow control. |
| VMware guest integration | Included in both VMware profiles (same probing code in other editions). ## Windows and IMP applications

EXE launch still automatically links PE32/PE32+ to an IMP1 page image. The 1.1 import ordinals have not changed. Each invocation resets interpreted registers, stack, image/heap state, error state, and file handle. New imports include `GetVersion`, `GetVersionExA/W`, `GetProductInfo`, `GetSystemMetrics` (screen dimensions), `GetCurrentThreadId`, `CreateFileA`, `ReadFile` and `CloseHandle`. The compatibility profile reports NT **10.0.22631**, workstation, Professional product code 48. This is a response to version queries, not Windows running in a container.

Plain `MessageBoxA/W` calls now draw a native modal and **wait for a click or Enter** before returning IDOK. Win32 files and prelinked IMPs can open one flat lowercase Home `.txt` file at a time (up to 16 KiB): `GENERIC_READ + OPEN_EXISTING` or `GENERIC_WRITE + CREATE_ALWAYS`. Writes stage in guest-specific memory. **CloseHandle** asks the user to allow/deny saving a version. Enter/Esc denies; click Allow or press Y to commit. An unclosed handle is discarded. No raw disk, kernel pointers, arbitrary paths, or device I/O exposed to apps.

**Try it on writable Home:** in F3 type `convert postcard.exe`, then `open postcard.imp`. Click Allow, minimize with F4, and type `cat postcard.txt`. The sample checks the Windows build and edition before creating its note. `open hello64.exe` demonstrates the Win32 modal. There is no general HWND window manager, DirectX, registry, Windows installer, or guarantee for arbitrary EXEs.

## Linux executables and terminal

`open linux.elf` executes a real statically linked Linux x86-64 ELF, also runnable unchanged on x86-64 Linux. Loader: little-endian ET_EXEC, nonoverlapping PT_LOAD pages, executable entry, mapped span ≤2 MiB. Syscalls: stdout/stderr `write`, `exit`, `exit_group`, `getpid`, `gettid`, and read-only Home `.txt` via `open`/relative `openat(AT_FDCWD)`, `read`, `close`. Unknown calls return `-ENOSYS`; guest memory, instruction and output bounds apply. No ELF32, shared libraries, PT_INTERP, TLS, glibc environment, package manager, Linux GUI or kernel modules. No launch arguments yet. Use the offline Home tool's `put` with a `.elf` name to add a compatible binary.

Terminal and F3 command desktop share the same editor: arrows, Home/End, Delete, 16-command history, 96 lines of output, PgUp/PgDn scrollback, Ctrl+L and Ctrl+C (clear pending input). Try `help keys`, `help drivers`, `echo`, `pwd`, `dir`, `cat NAME.txt`, `ver`, `vmtools`, `storage`, `open`, `convert`, `save`, `prefs`, `tasks`. This is a FreshOS shell, not Bash or PowerShell; it does not implement POSIX pipelines, jobs or scripting.
